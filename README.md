# P2P 聊天（P2PChat）

跨公网即时通信，**无需服务器、无需公网 IP、免注册**。走免费公共 MQTT 中转，开箱即用。

> 最新版本：**v3.1.1** · 安装包见 [GitHub Releases](https://github.com/wayileina114-bit/p2p-chat/releases)

---

## ✨ 核心特性

**界面与账号**
- 🧭 **QQ 式单窗口**：左侧会话列表，右侧聊天区，点会话即切换
- 🌗 **暗色 / 浅色双主题**：默认暗色（参考 Discord），顶部一键切换并记住选择
- 👤 **免注册**：头像、昵称、用户 ID 都集成在主界面顶部——点头像换头像、昵称直接编辑、点「📋 复制ID」复制自己的 ID（未设置头像时按昵称显示彩色首字母）
- 💌 **跨房间私聊**：走全局隐藏通道，**不需要和对方同房间**，点左侧成员即可一对一私聊
- 🔍 **搜索**：顶部搜索框按名称快速定位会话 / 成员
- 🏠 **多房间**：一次可加入多个房间，每个房间独立的群聊 / 在线名单

**聊天能力**
- 💬 文字聊天（圆角气泡：自己靠右蓝色，对方靠左白色；同一人连续发言自动合并名字，像 Discord 一样清爽）
- 🖼 图片：聊天框内**直接内联预览**（低画质缩略图 → 自动接收原图，QQ 式）
- 📎 任意文件传输（**群聊 + 私聊**都能发）；非图片文件才弹「接收 / 拒绝」确认
- ⚡ **512KB 大分片 + 并发传输 + 局域网直连加速**：同一网段内自动走 TCP 直连，绕开公网中转，速度大幅提升（失败自动回退）
- 🖱 图片 / 文件**直接拖拽**到输入框或聊天区即可发送（点「📎」还可**一次多选多个文件**）
- 🛡 MD5 + 大小校验，收到的文件存到 `downloads/` 文件夹
- 📍 文件消息记住保存路径，右键可「打开文件位置 / 复制路径」
- 🚀 大文件收发**流式处理**，内存占用极小，低配机也能传 200MB 大文件

**社交互动（v2.x 新增）**
- @ 提及（自动弹出成员列表 + 提及高亮）
- 已送达 / 已读双层回执（消息下方显示谁看过了）
- 表情回应（👍❤️😂😮😢🙏）+ 引用回复 + 消息转发 + 收藏联系人
- 消息编辑 / 撤回 / 置顶 / 双击复制 / 悬停显示时间
- 正在输入提示 + 成员列表点击私聊 + 新消息分隔线
- Windows 原生通知（后台也能看到新消息）+ 免打扰
- 设置中心（通知/提示音/自动连接/免打扰/加密口令/自定义服务器）

**体验与可靠性**
- 💾 **对话历史自动保存**：群聊 / 私聊记录，断开重连、重启都不丢（历史较长时点「更早消息」可展开全部）
- ⏱ 消息时间戳 + 日期分隔线 + 右键复制消息
- 🔴 未读消息红色徽标（99+ 显示），窗口标题实时显示连接状态与在线人数
- 🔊 新消息提示音（默认开启，可在「设置」关闭）
- 🗑 清空会话记录 / 删除私聊会话
- 🔄 **应用内自动升级**：启动后后台检查 GitHub 最新版本，发现新版一键「下载并安装」，无需手动更换安装程序
- 🧩 **启动自动检测运行环境**，缺什么一键补装
- 🛡 崩溃日志兜底：异常自动写入 `crash.log` 并弹窗提示，便于快速定位

> 🔒 支持**端到端加密**（可选）：设置统一口令后，文字与文件全部 AES 认证加密后再传输；未设口令时正常明文。

## 📦 下载与安装

### 方式一：安装版（推荐）

从 [GitHub Releases](https://github.com/wayileina114-bit/p2p-chat/releases) 下载最新 `P2PChat-Setup.exe`：

1. 双击运行安装向导（**简体中文界面**）；
2. 若本机已安装旧版本，安装器会**自动检测到**并询问是否先卸载旧版本再覆盖安装（聊天记录与头像不受影响）；
3. 按提示完成安装即可，桌面会生成「P2P聊天」图标。空电脑也能直接装好运行，无需预装任何环境。

### 方式二：免安装 exe 版

打包产物 `dist\P2PChat\P2PChat.exe` 可直接双击运行，**免装任何环境**。
> ⚠️ onedir 模式下必须**把整个 `P2PChat` 文件夹一起分发**，不能只发单个 exe。

### 方式三：源码运行（推荐开发用）

双击 **`启动聊天.bat`**：自动检测 Python 与依赖 → 缺什么界面上一键补装 → 自动进入聊天主界面。

等价命令：

```bash
python launcher.py           # 图形界面：环境自检 + 一键装 + 自动启动
python launcher.py --cli     # 命令行自检（缺依赖自动装）
```

## 🧭 使用流程

1. 启动后**直接进入主界面**（无需登录），顶部编辑「昵称」、点头像可换头像；
2. 顶部「房间」框输入房间名，点「**＋ 加入**」（可加入多个房间）；
3. 启动后**默认自动连接**（可在「设置 → 启动时自动连接」关闭）；手动可点「连接 / 断开」切换；
4. 左侧会话列表分三段：
   - **群聊**：每个房间一个会话，点 ✕ 可退出；
   - **私聊**：历史 / 进行中的私聊（● 在线 / ○ 离线）；
   - **在线成员**：当前所有在线的人，**点击即发起私聊**（跨房间也能聊）；
5. 群聊里打字回车发送，发文件 / 图片点「📎 文件/图片」或拖拽，对方确认后传输；
6. 找人：顶部**搜索框**输入名称快速定位。

## 🔄 自动更新

- 启动时后台静默检查 [GitHub Releases](https://github.com/wayileina114-bit/p2p-chat/releases) 最新版本；
- 发现新版会弹窗展示版本号与更新内容，点「**下载并安装**」即可自动下载最新安装包并运行，全程无需手动到网页下载；
- 「帮助 → 检查更新」可随时手动检查。

---

## 🗂 数据存储

- 默认把数据（头像、昵称、ID、聊天记录、收到的文件）保存在 **程序所在目录**（便携）；
- 当程序目录不可写（例如安装到 `Program Files`）时，会自动改为存到 **`%APPDATA%\P2P聊天`**；
- 目录结构：`history/`（历史 + 身份 + 房间列表）、`downloads/`（收到的文件）。

## 🛠 开发者：源码运行与打包

### 依赖

- Python ≥ 3.9
- `paho-mqtt` `Pillow` `customtkinter` `tkinterdnd2`

一键安装：双击 **`安装环境.bat`**（缺 Python 会尝试用 `winget` 装，没有则打开官网下载页）。

### 重新打包 exe

双击 **`build_exe.bat`**：用 `--onedir` 打包生成 `dist\P2PChat\`，并压缩出 `dist\P2PChat-win.zip`。

### 生成安装包（Inno Setup）

```bash
# 1. 先打包 onedir
build_exe.bat
# 2. 用 Inno Setup 6 编译安装脚本
iscc installer\p2pchat.iss        # 产物：installer\P2PChat-Setup.exe
```

发新版本时，更新四处版本号：

| 位置 | 字段 |
| --- | --- |
| `chat_gui.py` | `APP_VERSION` |
| `installer\p2pchat.iss` | `#define MyAppVersion` |
| `README.md` | 顶部「最新版本」 |
| `CHANGELOG.md` | 新增版本条目 |

然后把 `P2PChat-Setup.exe` 上传为新的 GitHub Release，客户端即可自动检测到。

## 🌐 免费公共服务器

默认 `broker.emqx.io:1883`。连不上可换 `broker.hivemq.com`、`test.mosquitto.org`（端口 1883），修改 `chat_gui.py` 顶部 `DEFAULT_BROKER` 即可。

## ⚠️ 安全说明

消息与文件走公共服务器中转，**明文传输**，正常聊天没问题，**不要传敏感 / 私密内容**。如需更高安全性，可在工具层叠加端到端加密（例如 AES）。
