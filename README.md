# P2P 聊天（图形界面版）

跨公网聊天，**无需公网 IP、无需服务器、免注册**。走免费公共 MQTT 中转。

## 功能

- 💬 文字聊天（圆角气泡，自己的消息靠右、蓝色，对方靠左、白色）
- 🏠 **多房间**：一次可加入多个房间，每个房间独立的群聊/在线名单
- 👥 自动发现在线成员、掉线自动重连
- 🧭 **QQ 式单窗口**：左侧会话列表，右侧聊天区，点会话即切换
- 💌 **私聊（跨房间）**：走全局隐藏通道，**不需要和对方同房间**，点左侧成员即可一对
- 🔍 **搜索**：顶部搜索框按名称快速定位会话/成员
- 💾 **对话历史**：群聊/私聊记录自动存到 程序/exe 所在目录 `history/`，断开重连、重启后自动恢复
- 🖼 图片：聊天框内直接预览
- 📎 任意文件传输（在群聊里发起）
- ✅ 收发文件前**弹窗确认「接收 / 拒绝」**（对方同意才传）
- ⚡ 256KB 大分片 + 二进制直传，速度比旧版快一个量级
- 🖱 图片 / 文件**直接拖拽**到输入框或聊天区即可发送
- 🛡 MD5 + 大小校验，收到的文件存到程序目录下 `downloads/` 文件夹
- 🧩 **启动时自动检测运行环境，缺什么一键安装**
- ⚙️ 软件内「帮助」菜单：**环境检测 / 关于**、**打开收件文件夹**
- 🚀 性能优化：聊天记录/会话列表自动裁剪，长时运行不卡；关闭秒退不卡死；onedir 打包启动更快

## 一、三种运行方式

| 方式 | 做法 | 是否需要装环境 |
| --- | --- | --- |
| ① exe 版（最简单） | 双击 `dist\P2PChat\P2PChat.exe` | ❌ 不需要 |
| ② 源码版（推荐开发用） | 双击 **`启动聊天.bat`** | 自动检测+自动装 |
| ③ 手动装环境 | 双击 **`安装环境.bat`** | 一次性装好全部前置，再运行② |

### ② 源码运行（自动检测环境）

双击 **`启动聊天.bat`**，它会：

1. 检测有没有 Python、版本够不够、四个依赖库齐不齐；
2. **缺什么，界面上一键点「安装」就自动补**（调的就是系统 `pip`）；
3. 全部就绪后自动进入聊天主界面。

等价命令：

```bash
python launcher.py          # 图形界面：自检 + 一键装 + 自动启动
python launcher.py --cli    # 命令行自检（缺依赖自动装）
```

### ③ 一键安装所有前置

双击 **`安装环境.bat`**：

- 没装 Python → 自动尝试用 `winget` 装；没有 winget 则自动打开 Python 官网下载页；
- 已装 Python → 自动升级 pip 并安装全部依赖：
  `paho-mqtt` `pillow` `customtkinter` `tkinterdnd2`

## 二、使用流程

1. 打开程序，填「昵称」；顶部「房间」框输入一个房间名，点「**＋ 加入**」，可重复加入多个房间；
2. 点「**连接**」开始聊天（可连上后再继续加房间）；
3. 左侧「会话列表」分三段：
   - **群聊**：每个房间一个会话，点房间的 ✕ 可退出该房间；
   - **私聊**：历史/正在进行的私聊（● 在线 / ○ 离线）；
   - **在线成员**：当前所有在线的人，**点击即发起私聊**（跨房间也能聊）；
4. 群聊：切到对应房间，直接打字回车发送；发图片/文件点「📎 文件/图片」或拖拽，对方会弹窗确认；
5. 找人：顶部**搜索框**输入名称，快速定位会话。

> - 所有聊天记录会**自动保存**（存在 exe/程序目录 `history/`），**断开重连、重启都不丢**；
> - 私聊走**全局隐藏通道**，不依赖是否同房间；
> - 窗口顶部菜单「帮助」里可查看**环境检测 / 关于**，也能访问**打开收件文件夹**。

## 三、重新打包 exe

双击 **`build_exe.bat`**，自动完成三件事：

1. 用 `--onedir` 打包（**启动快**，不用每次运行都解压）；
2. 生成可运行目录 `dist\P2PChat\`（双击里面的 `P2PChat.exe`）；
3. 压缩出 `dist\P2PChat-win.zip` 方便分发。

> ⚠️ onedir 模式下**必须把整个 `P2PChat` 文件夹（或 zip）一起发给别人**，不能只发单个 exe。

## 四、文件列表

| 文件 | 说明 |
| --- | --- |
| `dist/P2PChat/` | 打包好的 Windows 程序目录（免环境，双击里面 `P2PChat.exe`） |
| `dist/P2PChat-win.zip` | 上面目录的压缩包，方便整个发给别人 |
| `launcher.py` | 启动器：环境自检 + 一键安装 + 自动启动 |
| `chat_gui.py` | 图形界面源码（QQ 式布局 + 多房间 + 跨房间私聊 + 历史记录 + 文件收发 + 启动自检） |
| `chat.py` | 命令行版源码（局域网直连 / 远程 MQTT） |
| `启动聊天.bat` | 双击入口（调 launcher，自动检测环境） |
| `安装环境.bat` | 一键装 Python + 全部依赖 |
| `build_exe.bat` | 一键打包 exe（onedir + 自动压 zip） |

## 五、免费公共服务器

默认 `broker.emqx.io:1883`。连不上可换 `broker.hivemq.com`、`test.mosquitto.org`（端口 1883），修改 `chat_gui.py` 顶部 `DEFAULT_BROKER` 即可。

## 六、安全说明

消息与文件走公共服务器中转，**明文传输**，正常聊天没问题，**不要传敏感/私密内容**。可加端到端加密（AES）再扩展。

## 七、关于 apk（Android）

Python 代码无法直接变成 apk，且需在 Linux/macOS 或云端编译。可行路线：

1. **Kivy + Buildozer**：用 Python + Kivy 重写 GUI，GitHub Actions 免费云端打包成 apk；
2. **网页版（PWA）**：做成网页，手机浏览器直接可用，再用 Capacitor/TWA 包成 apk。
